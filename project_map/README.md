# Project Map

This directory is the planning registry for Experts. It describes intended ownership and implementation targets without changing application code.

## Registries

- [Feature Registry](feature_registry.md): MVP feature areas and likely implementation ownership.
- [Screen Registry](screen_registry.md): planned screens, states, and required UI surfaces.
- [Data Registry](data_registry.md): planned models, services, repositories, and persistence.
- [Decision Registry](decision_registry.md): product and engineering decisions that should stay stable during MVP work.
- [Finnhub Endpoint Matrix](finnhub_endpoint_matrix.md): verified Finnhub endpoint behavior and current access limits.
- [Twelve Data Chart Provider](twelve_data_chart_provider.md): chart provider behavior and timeframe mapping.
