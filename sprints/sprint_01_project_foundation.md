# Sprint 1 - Project Foundation

## Goal

Establish the app foundation for a Cupertino-only Experts MVP without building feature depth yet.

## Checklist

- [x] Confirm app entry uses a Cupertino root.
- [x] Confirm Riverpod is wired at the app root.
- [x] Create the first stable folder/module boundaries for core, features, models, providers, and repositories.
- [x] Add a lightweight app shell placeholder with English-only copy.
- [x] Document any dependency gaps before adding packages.

## Acceptance Criteria

- App foundation is ready for feature teams to attach screens and providers.
- No Material app shell or Material-first UI patterns are introduced.
- All visible placeholder UI copy is English.
- Any package additions needed for later sprints are listed before implementation.
