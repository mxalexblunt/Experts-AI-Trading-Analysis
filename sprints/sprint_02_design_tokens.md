# Sprint 2 - Design Tokens

## Goal

Translate `DESIGN.md` into centralized Flutter design tokens.

## Checklist

- [x] Add centralized color tokens for canvas, surfaces, text, primary, semantic movement, borders, and shadows.
- [x] Add centralized typography tokens using system SF Pro defaults.
- [x] Add spacing, radii, and shadow helpers.
- [x] Add reusable Cupertino button/input/card styling helpers where useful.
- [x] Replace any temporary hardcoded colors or text styles touched by this sprint.

## Acceptance Criteria

- Feature widgets can consume shared design tokens instead of hardcoding visual values.
- The app remains light-only.
- Letter spacing is `0`.
- Standard cards and controls follow the design radii and spacing rules.
