# Sprint 5 - Market Data Models

## Goal

Define market data models and repository contracts before building data-driven screens.

## Checklist

- [x] Create models for assets, quotes, chart points, and news items.
- [x] Define repository interfaces for search, quote/profile lookup, chart data, and news.
- [x] Add placeholder or mock implementations only where needed to unblock UI.
- [x] Document Finnhub endpoint assumptions and unknowns.
- [x] Model loading, empty, and error result states.

## Acceptance Criteria

- Feature code has stable typed contracts for market data.
- Repository contracts can support stocks and ETFs.
- Unknown Finnhub plan/rate-limit details are visible for follow-up.
- No real API key is committed or printed.
