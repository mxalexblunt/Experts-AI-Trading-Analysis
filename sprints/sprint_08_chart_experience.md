# Sprint 8 - Chart Experience

## Goal

Add the simple chart and timeframe experience for Asset Details.

## Checklist

- [x] Add chart rendering for available quote/history data.
- [x] Add timeframe selector for 1D, 1W, 1M, 6M, and 1Y.
- [x] Handle loading, empty, and unavailable chart states.
- [x] Use tabular number formatting for chart-adjacent financial values.
- [x] Keep chart visuals aligned with the light fintech design system.

## Acceptance Criteria

- Users can switch supported timeframes.
- Chart states are clear when data is unavailable.
- The chart does not use dark mode or decorative gradients.
- Chart styling is token-driven and readable on mobile.
