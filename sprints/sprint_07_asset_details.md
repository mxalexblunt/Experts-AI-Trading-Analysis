# Sprint 7 - Asset Details

## Goal

Build the core Asset Details screen for a selected stock or ETF.

## Checklist

- [x] Display symbol, company name, asset type, and watchlist icon button.
- [x] Display price, absolute change, and percent change.
- [x] Add a chart card placeholder or connected chart component.
- [x] Add optional screenshot and note entry sections.
- [x] Add Analyze action entry point.
- [x] Add market-data unavailable state.

## Acceptance Criteria

- Asset Details gives enough context before AI analysis.
- Watchlist add/remove is available without text-heavy controls.
- Price movement uses semantic up/down tokens.
- Analyze does not bypass the future AI consent gate.
